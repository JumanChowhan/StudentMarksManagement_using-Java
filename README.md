# Menu Driven Array Project

## 📌 Project Description

This is a simple Java-based **Menu Driven Array Project** designed to manage and analyze student marks. The program uses arrays, loops, conditional statements, and a switch statement to perform different operations through a menu.

## 🎯 Objective

The main objective of this project is to practice:

* Arrays
* Loops
* Switch statements
* Conditional statements
* Basic calculations
* User input using `Scanner`

## ⚙️ Features

The program provides the following options:

1. **Insert Marks** – Enter marks for students.
2. **Display Marks** – Display all entered marks.
3. **Total and Average** – Calculate total and average marks.
4. **Highest and Lowest** – Find the highest and lowest marks.
5. **Exit** – Close the program.

## 🧠 Algorithm

1. Start the program.
2. Ask the user to enter the number of students.
3. Create an array to store student marks.
4. Display the menu.
5. Ask the user to select an option.
6. Perform the selected operation:

   * Insert marks
   * Display marks
   * Calculate total and average
   * Find highest and lowest marks
7. Continue displaying the menu until the user selects **Exit**.
8. End the program.

## 💻 Technologies Used

* **Programming Language:** Java
* **Input:** Scanner
* **Data Structure:** Array
* **Control Statements:** `if`, `switch`, `for`, and `while`

## 📂 Project Files

* **Program** – Contains the Java source code and output screenshots.

## ▶️ How to Run

1. Install Java/JDK on your computer.
2. Open the Java file in an IDE such as IntelliJ IDEA, Eclipse, or VS Code.
3. Compile and run the program.
4. Enter the number of students and use the menu to perform different operations.
